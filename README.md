# 太吾异世劫 Wiki（玩家资料站）+ TaiwuDpsMeter

本仓库包含两部分：

- **Wiki 站点**（仓库根目录，经 GitHub Pages 发布）：功法图鉴 / 装备图鉴与词缀 / 丹药图鉴 / 灵侍图鉴 / BD 构筑台 → https://fengling235.github.io/taiwuyishijie-wiki/
- **TaiwuDpsMeter**（`plugin/`）：DPS 统计与训练工具（BepInEx 插件）→ 见 [plugin/TaiwuDpsMeter](plugin/TaiwuDpsMeter/README.md)

数据为玩家社区整理，与官方无关；游戏版本更新后数值可能变动，以游戏内实际为准。
Wiki 部分由本地数据管线自动构建发布，不接受直接修改数值的 PR（欢迎指出错误）。
